# Design

## Status

Layout wireframe only. No visual direction has been chosen for this surface.

## Visual Authority

The design specification in `docs/03-design/design.md` is a pinned, incomplete brand awaiting full render and approval. It is NOT yet implemented in this wireframe. This document records the wireframe's actual state so live mode can operate without mistaking an undecorated skeleton for a finished visual system.

## System (as built in the wireframe)

- **Purpose:** single landing page; layout and spacing only. No colors, typography, gradients, glass, mascots, or imagery are committed yet.
- **Surfaces:** neutral light canvas (`#f5f7fa`); white cards; dashed neutral borders; rounded boxes.
- **Type:** system-ui stack only; sizes are layout stubs, not design decisions.
- **Spacing:** 4px base scale: 4, 8, 12, 16, 24, 32, 48, 64, 80, 96, 128px.
- **Layout:** 1280px max container; mobile inset 16px / desktop 48px; mobile-first 1-col stacking to 2-col (≥640px) and 3-col (≥1024px) grids.
- **Components (boxes):** neutral rounded placeholders. No visual identity.

## Constraints

- The wireframe exists to refine spacing, rhythm, and section order only.
- Design direction (palette, type, mascots, motifs, glass) is deliberately absent and will be applied later from `docs/03-design/design.md` once approved.
- Live variants must remain within this undecorated, layout-focused register: spacing, density, alignment, and structure — not color, type, or aesthetic.

## Open Decisions

- Final visual direction (deferred until the design spec is rendered and approved).
- Approved logo, fonts, mascot art, and content records (human inputs).
