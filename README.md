# AWS Student Builder Groups Haribon Website

Repository for the future website of AWS Student Builder Groups Haribon, a university-based AWS community chapter.

## Current phase

This repository is in project foundation and discovery. No application has been initialized and no product features have been implemented.

The project will use:

- Next.js for the future web application
- The Spiral SDLC model for iterative planning, risk analysis, engineering, and evaluation
- Repository-local agent skills under `.agents/skills`

Project requirements, branding, content, and the PRD will be added in later phases.

## Repository map

- `.agents/skills/` - project-local design and software-engineering skills
- `docs/` - governance, discovery, Spiral cycles, design, engineering, quality, and operations records
- `public/` - placeholders for future public brand and media assets
- `src/` - placeholders for the future Next.js application
- `tests/` - placeholders for future automated test suites
