# Cycle Template

Record the cycle owner, dates, scope, assumptions, and approval status here.

Use the numbered directories in order:

- `01-objectives/` - goals, alternatives, constraints, and success measures
- `02-risk-analysis/` - risks, likelihood, impact, mitigations, and decision gates
- `03-engineering/` - approved prototypes, documents, or implementation evidence
- `04-evaluation/` - stakeholder feedback, outcomes, lessons, and next-cycle decision
