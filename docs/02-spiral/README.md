# Spiral SDLC

Each cycle repeats four activities:

1. Define objectives, alternatives, constraints, and success criteria.
2. Identify, assess, and mitigate the highest-priority risks.
3. Engineer only the artifacts or product increment authorized for that cycle.
4. Evaluate the result with stakeholders and decide the next cycle.

Copy `_cycle-template/` when a new cycle is approved. `cycle-00-foundation/` records the current repository and process setup; it does not authorize product implementation.
