# Haribon Campaign Reference Archive

Status: design reference only  
Captured: 2026-08-19  
Production use: not automatically approved

These files preserve visual evidence supplied during the website design phase. They are stored under documentation so future designers can study their composition without automatically publishing them through the website.

The examples contain historical campaign dates, contact details, organization-name variants, and application copy. None of that embedded text is authoritative website content. The current PRD remains the source of truth for public naming, routes, and content.

## Usage Rules

- Recreate useful patterns as responsive HTML, CSS, approved images, and design tokens.
- Do not ship these files merely because they exist in the repository.
- Do not treat baked-in text as accessible or searchable website content.
- Do not copy personal names, application dates, contact details, or campaign claims into the site.
- Do not use a historical organization-name variant in live copy.
- Verify logo, mascot, photography, and illustration permissions before production use.
- Decorative studies derived from these files must remain subordinate to content and controls.
