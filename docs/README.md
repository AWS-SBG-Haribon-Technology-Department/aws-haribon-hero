# Project Documentation

Documentation is organized by project concern while development progresses through repeatable Spiral cycles.

## Sections

- `00-governance/` - charter, stakeholders, decisions, and project ownership
- `01-discovery/` - research, requirements, and the future PRD
- `02-spiral/` - cycle template and records for each project iteration
- `03-design/` - brand, information architecture, UX, and UI artifacts
- `04-engineering/` - architecture, technical decisions, data, and security
- `05-quality/` - test plans, accessibility checks, and review evidence
- `06-release-operations/` - deployment, runbooks, and post-release records

Do not treat placeholder directories as approved requirements. Their contents will be defined through the SDLC process.
